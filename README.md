# Se7en — Arabic Sportswear Gallery (V4)

معرض عربي RTL لعرض تيشرتات Se7en فقط، من غير أسعار أو سلة شراء.

## What's included
- Cinematic animated intro with the actual three product photos, skip and enter controls, session-level display, and reduced-motion support.
- Dark premium interface with lime accents, motion reveal, responsive layout, and mobile navigation styling.
- Product filters for all designs, الأهلي، الزمالك، وبرشلونة.
- Product detail lightbox with zoom-in / zoom-out controls.
- Responsive map embedded in the page, address block, and optional directions link.
- Instagram profile link.
- Lazy-loaded product card images, Arabic SEO description, Open Graph metadata, and no build step.

## Preview locally
Open `index.html`, or run:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.

## Deploy to Vercel
1. Extract the zip.
2. Put the contents of this folder directly in the root of the GitHub repository: `index.html`, `vercel.json`, and `assets/`.
3. Redeploy on Vercel using the **Other** framework preset with no build command and `.` as the output directory if a directory is required.

The gallery intentionally has no prices, checkout, cart, or online payment.
