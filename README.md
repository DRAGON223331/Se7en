# Se7en Store — V6

Arabic right-to-left sportswear gallery. No prices and no checkout.

## What changed in V6
- Intro is shown on each fresh page load and works even when reduced-motion is enabled.
- Intro can be dismissed using the buttons, Enter/Escape, a mouse-wheel scroll down, or an upward swipe on touchscreens.
- The page remains scrollable; the intro dismisses on a downward mouse-wheel scroll or upward touch swipe, and auto-closes after 9 seconds as a failsafe.
- Shirt photo backgrounds and wooden hangers are removed for floating transparent product PNGs.
- Product gallery, hero, intro, and enlarged image view all use the transparent cut-outs on dark backgrounds.
- Product names remain: تيشرت برشلونة، تيشرت الأهلي، تيشرت الزمالك.
- Map stays embedded, and Instagram / location links are maintained.

## Deploy to Vercel
Upload the contents of this folder to the root of the connected GitHub repository. `index.html`, `assets/`, and `vercel.json` must be at the repository root. Set Framework Preset to `Other`, leave Build Command empty, and set Output Directory to `.` if required, then redeploy.

The gallery is informational only. It has no prices, cart, or online checkout.
