# Se7en Store — V18

واجهة معرض ملابس رياضية باللغة العربية (RTL)، بهوية سوداء وبيضاء، مع أسعار موحّدة وزر للتسجيل والتواصل مع اثنين من مسؤولي خدمة العملاء عبر واتساب.

## تشغيل الموقع محليًا
- افتح `index.html` أو شغّل `python -m http.server 8080` ثم افتح `http://localhost:8080`.

## أرقام خدمة العملاء
- تم إعداد الرقمين داخل `store-config.js` بصيغة دولية (أرقام فقط).
- يمكن تعديل أسماء المسؤولين أو أرقامهم من `window.SE7EN_CONFIG.sellers`.
- الموقع يعرض للمستخدم اختيار مسؤول خدمة العملاء الذي يريد التواصل معه عند التسجيل أو الاستفسار عن منتج.

## ملاحظة مهمة عن التسجيل
زر التسجيل يجهّز رسالة واتساب تحتوي الاسم ورقم واتساب العميل، ثم يسمح له باختيار أحد المسؤولين. العميل يراجع الرسالة ويضغط إرسال بنفسه داخل واتساب؛ الموقع لا يخزّن بيانات العميل ولا ينفّذ تسجيل دخول موثّق أو إرسال OTP. تفعيل تسجيل دخول حقيقي برمز تحقق يحتاج خادمًا وإعداد WhatsApp Business Platform.

## النشر على Vercel
- ارفع محتويات المجلد إلى جذر مستودع GitHub.
- اختر Framework Preset: `Other`، واترك Build Command فارغًا وOutput Directory على `.`.
- نفّذ Deploy أو Redeploy.

## تحديث V18
- إضافة اختيار بين رقمي خدمة العملاء عند التسجيل أو التواصل العام أو الاستفسار عن منتج.
- وضع الرقمين في `store-config.js`.
- الحفاظ على المنتجات الـ11 وأسعار 350 جنيهًا والفلاتر والصور الحالية.
