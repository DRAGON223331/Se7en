# Se7en Store — V17

واجهة معرض ملابس رياضية باللغة العربية (RTL)، بهوية سوداء وبيضاء، مع أسعار موحّدة وزر للتواصل مع البائع عبر واتساب.

## تشغيل الموقع محليًا
- افتح `index.html` أو شغّل `python -m http.server 8080` ثم افتح `http://localhost:8080`.

## إعداد رقم واتساب البائع (مطلوب قبل النشر)
1. افتح ملف `store-config.js`.
2. ضع رقم واتساب البائع في `sellerWhatsApp` بصيغة دولية، أرقام فقط من غير `+` أو مسافات. مثال التنسيق المصري: `2010XXXXXXXX`، مع استبدال Xs بالرقم الحقيقي.
3. احفظ الملف ثم ارفع كل ملفات المجلد إلى Vercel.

زر التسجيل يجهّز رسالة واتساب تحتوي الاسم ورقم العميل، وزر كل منتج يجهّز رسالة خاصة بالتيشيرت وسعره (350 جنيه). العميل يراجع الرسالة ويضغط إرسال داخل واتساب؛ الموقع لا يخزّن بيانات العميل ولا ينفّذ تسجيل دخول موثّق أو إرسال OTP. تفعيل تسجيل دخول حقيقي برمز تحقق يحتاج خادمًا وإعداد WhatsApp Business Platform.

## النشر على Vercel
- ارفع محتويات المجلد إلى جذر مستودع GitHub.
- اختر Framework Preset: `Other`، واترك Build Command فارغًا وOutput Directory على `.`.
- نفّذ Deploy أو Redeploy.

## تحديث V17
- إضافة واجهة تسجيل / تواصل عبر واتساب تجمع اسم العميل ورقم واتسابه ثم تجهّز رسالة يراجعها ويرسلها يدويًا.
- إضافة زر تواصل مباشر مع البائع في الهيدر وقسم الموقع، وزر يسأل البائع عن المنتج داخل نافذة تفاصيله.
- إعداد رقم البائع من `store-config.js` لتجنب تخمين رقم هاتف غير مُعطى.
- لا تُخزّن بيانات العملاء في المتصفح، ولا يوجد تحقق OTP أو حساب دائم بدون خادم.
- الحفاظ على المنتجات الـ11 وأسعار 350 جنيهًا والفلاتر والصور الحالية.
