# Se7en Store — V8 (Black & White)

معرض عربي لتيشرتات Se7en، بدون أسعار أو سلة شراء، مع خريطة مدمجة ورابط إنستجرام.

## الهوية الجديدة
- هوية بصرية أبيض وأسود فقط للواجهة.
- مقدمة سينمائية: دائرة تتفتح، ثم تيشرت الزمالك، ثم الأهلي، ثم برشلونة بالتتابع، وبعدها يظهر الاسم «سيفن — Se7en».
- المقدمة تفضل ظاهرة حتى تكتمل؛ يقدر الزائر دخول المعرض أو تخطي المقدمة أو تمرير الصفحة لأسفل، وتختفي تلقائيًا بعد انتهاء التسلسل مع إبقاء الاسم ظاهرًا لعدة ثوانٍ.
- الصور الأصلية المعزولة بصيغة PNG موجودة في `assets/products/`.
- تصميم متجاوب مع الموبايل، وفلاتر للمنتجات، ونافذة تكبير، وخريطة مدمجة.

## النشر على Vercel
ارفع محتويات المجلد إلى جذر المستودع المرتبط بـ Vercel، بحيث يكون `index.html` ومجلد `assets/` و`vercel.json` في المستوى نفسه. استخدم `Other` كإطار عمل، من غير أمر Build، وOutput Directory `.` ثم نفّذ Redeploy. بعد النشر استخدم `Ctrl + Shift + R`.
