# Se7en Store — V7

نسخة معرض عربية جاهزة للنشر على Vercel، بدون أسعار أو سلة شراء.

## إصلاح الانترو
- الانترو يظهر عند فتح الصفحة ويظل ظاهرًا حتى يختار الزائر «ادخل المعرض» أو «تخطي المقدمة».
- لا يتم إغلاقه تلقائيًا بعد عدة ثوانٍ.
- تجاهل حركة عجلة الماوس/التاتش باد أول 1.4 ثانية حتى لا تختفي المقدمة بسبب حركة غير مقصودة أثناء تحميل الصفحة.
- الضغط على Escape يغلق الانترو، والتمرير المقصود لأسفل يغلقه وينقلك إلى الصفحة.
- السكرول يرجع طبيعيًا بمجرد إغلاق الانترو.

## النشر
ارفع محتويات المجلد بحيث يكون `index.html` و`assets/` و`vercel.json` في جذر المشروع، ثم نفّذ Redeploy على Vercel. بعد النشر افتح الموقع مع Ctrl+F5.
