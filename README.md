# Se7en Store — V10

واجهة معرض ملابس رياضية باللغة العربية (RTL)، بهوية سوداء وبيضاء، من غير أسعار أو دفع إلكتروني.

## التشغيل محليًا
- افتح `index.html` مباشرةً أو شغّل `python -m http.server 8080` ثم افتح `http://localhost:8080`.

## النشر على Vercel
- ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
- اختر Framework Preset: `Other`، واترك Build Command فارغًا وOutput Directory على `.`.
- نفّذ Deploy أو Redeploy.

## الموجود في النسخة
- Intro سينمائي بدائرة وثلاثة تيشرتات ثم شعار «سيفن — Se7en».
- معرض بصور شفافة محسنة بصيغة WebP، وفلاتر حسب الفريق.
- نافذة صورة مكبرة مع تكبير/تصغير والتنقل بين المنتجات بالأسهم أو لوحة المفاتيح.
- مؤشر تقدم التمرير، زر رجوع لأعلى، وانتقالات ظهور تدريجية.
- قسم صور من المعرض مرتبط بحساب Instagram، وخريطة مدمجة داخل الصفحة.
- تحسينات SEO وبيانات منظمة، مع دعم `prefers-reduced-motion`.

المعرض تعريفي فقط: لا توجد أسعار أو سلة مشتريات أو تكامل دفع.
