# Se7en Store — V15

واجهة معرض ملابس رياضية باللغة العربية (RTL)، بهوية سوداء وبيضاء، من غير أسعار أو دفع إلكتروني.

## التشغيل محليًا
- افتح `index.html` مباشرةً أو شغّل `python -m http.server 8080` ثم افتح `http://localhost:8080`.

## النشر على Vercel
- ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
- اختر Framework Preset: `Other`، واترك Build Command فارغًا وOutput Directory على `.`.
- نفّذ Deploy أو Redeploy.

## الجديد في V11
- قسم إنستجرام بتصميم تحريري مميز، مع بطاقة حساب `@se7e_n770` ودعوة متابعة واضحة.
- كولاج تفاعلي لصور تيشرتات برشلونة والأهلي والزمالك، وروابط مباشرة للحساب.
- تأثيرات Hover وحركة مدار خفيفة، مع تخفيف الحركة للأجهزة التي تفضّل ذلك.
- الحفاظ على معرض المنتجات وفلاترها ونافذة الصور المكبرة والخريطة المدمجة.

ملاحظة: الصور في قسم التواصل مأخوذة من معرض Se7en المحلي وليست بثًا مباشرًا لمنشورات Instagram.


## الجديد في V12
- إضافة قسم آخر منشورات إنستجرام باستخدام التضمين الرسمي للحساب `@se7e_n770`، لعرض محتوى الحساب العام داخل الصفحة.
- يظهر رابط بديل للحساب لو التضمين غير متاح.
- ملاحظة: يتطلب عرض منشورات إنستجرام أن يكون الحساب عامًا وأن يكون خيار السماح بالتضمين مفعّلًا؛ المحتوى يأتي مباشرة من Instagram وليس محفوظًا محليًا.


## الجديد في V13
- توسيع معرض المنتجات من 3 إلى 11 تصميمًا.
- إضافة تصنيفات الأهلي والزمالك وبرشلونة ومانشستر يونايتد والبرازيل وطرابزون سبور وريال مدريد.
- تحسين صور المنتجات الجديدة لعرض متناسق على بطاقات المعرض، مع الاحتفاظ بالصورة الكاملة عند فتح التفاصيل.
- الحفاظ على طريقة العرض الحالية بدون أسعار أو دفع إلكتروني.
