# Se7en — المعرض العربي

موقع عرض منتجات باللغة العربية (RTL)، بدون أسعار أو عربة تسوق أو دفع إلكتروني. يحتوي على صور المنتجات الثلاثة الأصلية المرفقة، ونافذة لعرض كل صورة بحجم أكبر، ورابط إنستجرام وموقع المعرض على الخريطة.

## الملفات
- `index.html` — الصفحة والتنسيقات والتفاعلات.
- `assets/products/` — صور المنتجات التي أرسلها صاحب المتجر.
- `vercel.json` — إعدادات بسيطة للنشر على Vercel.

## التشغيل محليًا
افتح `index.html` في المتصفح، أو شغّل من جذر المجلد:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر على Vercel
ارفع محتويات المجلد إلى جذر مستودع GitHub، ثم استورد المشروع في Vercel. اختر `Other` كإطار العمل ولا تضف أمر Build أو Output Directory خاصًا بإطار عمل.
