🤖 ربط إشعارات الطلبات بتيليجرام (Telegram Bot)

يتم إرسال كل طلب شراء جديد فوراً ببيانات العميل كاملة (الاسم، الهاتف، العنوان، والمقاسات) إلى تيليجرام البائعين.

غير مربوط
تحصل عليه مجاناً بثوانٍ من بوت تيليجرام الرسمي @BotFather عند إنشاء البوت.
⚠️ تنبيه: لقد كتبت رقم هاتف! بوت تيليجرام لا يقبل أرقام التليفونات في حقل Chat ID، بل يتطلب الـ ID الرقمي لحسابك أو لجروب المحل. اضغط على زر "استخراج الـ Chat ID تلقائياً" لجلب الـ ID بضغطة واحدة، أو يمكنك استقبال الطلبات عبر أرقام التليفونات بالواتساب مباشرة!
يمكنك كتابة معرف حسابك، أو كذا معرف مفصولين بفواصل لإرسال الطلب لكذا شخص في نفس الوقت (12345678, 98765432)، أو معرف جروب تيليجرام به كل البائعين.

👥 قائمة مستلمي إشعارات الطلبات (أكثر من بائع)

كل بائع أو شريك مسجل هنا سيصله إشعار فوري على تيليجرام عند حدوث أي طلب شراء جديد من العملاء.

1 بائع مسجل

📡 سجل محاولات إرسال تيليجرام الأخيرة (Live Dispatch Logs)

📖 كيفية تجهيز بوت تيليجرام للطلبات في دقيقتين:

  1. افتح تطبيق تيليجرام وابحث عن @BotFather واضغط Start ثم أرسل /newbot.
  2. اختر اسماً للبوت واسم مستخدم ينتهي بـ bot، وسيعطيك HTTP API Token ضعه في الحقل أعلاه.
  3. افتح البوت الخاص بك واضغط Start. لمعرفة الـ Chat ID الخاص بك أو بجروب البائعين، ابحث عن @userinfobot وسيعطيك رقم الـ Id مباشرة، أو أضف البوت لجروب المحل.
  4. اضغط زر تجربة إرسال إشعار فوري أعلاه لتتأكد من وصول الرسالة بنجاح!
